## Job Description

NVIDIA is hiring a Software QA Development Engineer to work with cross-functional groups on test planning, execution, reporting, test automation, QA tooling, and integration tests. The role focuses on improving QA productivity, optimizing test plans, and identifying weak spots in software quality.

## Key Responsibilities

- Review product requirements and develop test matrices.
- Build test plans, design test cases, execute tests, and report bugs/results.
- Automate test cases and help design/implement test frameworks.
- Manage bug lifecycle and coordinate solutions across groups.
- Reproduce and verify customer issues/fixes in-house.

## Required Skills

- BS or higher degree, or equivalent experience, in CS/EE/CE.
- 3+ years of QA experience.
- Unix/Linux and shell/Python programming.
- Test case development, API/UI automation, and failure analysis.
- AI development tools for test case creation, automation, and code coverage.
- Model testing and LLM benchmarking.
- QA sense, detail orientation, data analysis, English communication, and teamwork.
