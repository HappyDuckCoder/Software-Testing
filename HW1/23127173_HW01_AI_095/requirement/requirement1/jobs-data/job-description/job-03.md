## Job Description

This QA Engineer role focuses on automation testing across API, backend, and UI layers, with additional scope in ML features, security/authentication testing, API partnerships, and client-facing integrations.

## Key Responsibilities

- Design, develop, and maintain automated test frameworks for API, backend, and UI layers.
- Execute automated test scripts and integrate automated tests into CI/CD pipelines.
- Apply shift-left testing, perform test planning, execution, and defect tracking.
- Analyze test results and provide quality insights.
- Support junior QEs and participate in code reviews and quality discussions.
- Validate ML-related features and data outputs.
- Test security, authentication, authorization, API partnerships, and third-party integrations.

## Required Skills

- 5+ years of Quality Control / Test Automation experience.
- Automation across API, backend, and UI.
- Playwright, Cypress, RestAssured, and Postman.
- Golang, TypeScript, Ruby, Python, or Java.
- Testing methodologies, SDLC, CI/CD, Docker.
- Analytical skills, communication skills, and English communication.

## Preferred Skills

- ML workflow or ML feature testing.
- Security testing, authentication, authorization, and encryption.
- API integration or third-party service validation.
- Microservices architecture and Kubernetes.

## Salary / Benefits

Salary: USD 1,800 - 2,000.

## AI / Automation Relevance

Strong AI relevance through ML feature testing, ML data-output validation, and automation testing.

## AI Impact Analysis

AI increases the need for QA engineers who can validate ML outputs, define reliable quality oracles, and test security-sensitive integrations. AI can help generate test cases, but the tester must decide what output is correct, safe, and stable.
