## Job Description

KMS Technology is hiring a Full-stack Test Engineer to execute manual and automation testing, improve product quality, and work closely with developers, business analysts, customer service, and operations teams.

## Key Responsibilities

- Execute manual and automation testing activities.
- Address automation needs with analytical and problem-solving skills.
- Automate functional, regression, and/or performance acceptance tests.
- Improve end-to-end automated test coverage.
- Work with Scrum teams to analyze requirements and recommend feature, smoke, and regression testing.

## Required Skills

- Intermediate English.
- 2+ years of manual and automation testing experience.
- Agile development methodology.
- Software testing process knowledge.
- API, web application, and preferably mobile testing.
- Requirement analysis, test strategy, test approach, test planning, black-box, risk-based, exploratory, and non-UI testing.
- Selenium, Playwright, or similar frameworks.
- C#, Java, JavaScript, Python, or another programming language.
- Postman, Git, IntelliJ IDEA, or similar tools.

## AI-related Nice-to-have Skills

- AI chat tools such as ChatGPT, Claude, or Gemini for research, debugging, and learning.
- AI coding assistants such as GitHub Copilot, Cursor, or Claude Code.
- Prompt writing for code snippets, unit tests, and documentation.
- Awareness of AI output limitations and responsible AI use, including privacy and sensitive client data.

## Salary / Benefits

Attractive salary and benefits. The posting mentions full salary during probation, 13th-month salary, performance bonus, premium healthcare insurance, 18+ paid leave days/year, and training opportunities.

## AI / Automation Relevance

Strong automation relevance and moderate AI relevance through AI chat tools, AI coding assistants, prompt writing, and responsible AI use.

## AI Impact Analysis

AI can help QA engineers draft tests, debug issues, and create documentation faster. The posting also highlights the need to understand AI limitations and data privacy, so AI should be used as support rather than accepted blindly.
