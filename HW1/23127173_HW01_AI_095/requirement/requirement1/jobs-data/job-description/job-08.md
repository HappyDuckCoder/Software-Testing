## Job Description

The QC Engineer establishes and standardizes the complete quality assurance process for Salesforce CRM systems and AI solutions. This foundational role builds QC practices from scratch, including automation testing frameworks, AI testing procedures, and quality standards for the engineering team.

## Key Responsibilities

- Establish the end-to-end QC process, including definition of done, bug severity matrix, and release checklist.
- Build and standardize automation testing for web UI, API, and Salesforce CRM flows.
- Integrate automated tests into CI/CD pipelines.
- Develop regression test suites for core system functionality.
- Define AI testing procedures such as prompt regression testing and output quality evaluation.
- Apply AI tools to accelerate test case generation, bug detection, and test data creation.
- Monitor AI model output degradation in production.
- Assess accuracy, consistency, and safety of AI agents before go-live.
- Test Salesforce flows, automation rules, data integrations, and data integrity.
- Produce quality reports and propose process improvements.

## Required Skills

- 2-3 years of QC/QA experience.
- At least one end-to-end automation testing project.
- Selenium, Playwright, Cypress, or equivalent.
- API testing tools such as Postman or RestAssured.
- Demonstrated use of AI tools such as Copilot, ChatGPT, or Claude in daily QC work.
- Basic Salesforce CRM knowledge.
- Ability to establish QC processes from scratch.

## Preferred Skills

- AI systems or LLM-based application testing.
- Python or JavaScript automation scripting.
- JMeter, k6, or Locust.
- Agile/Scrum, Jira, Salesforce Administrator certification.

Very strong AI relevance: the role explicitly covers AI testing procedures, prompt regression, output quality evaluation, AI model degradation monitoring, AI agents, and daily AI-tool use.
