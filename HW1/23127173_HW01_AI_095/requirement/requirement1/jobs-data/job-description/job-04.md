## Job Description

OPSWAT is hiring an Automation QA Engineer for the OESIS Framework team. The role ensures OESIS quality, reliability, and integration across diverse environments through automation-first and AI-driven testing.

## Key Responsibilities

- Design, develop, and maintain scalable automated test frameworks, preferably using Robot Framework and Python.
- Drive automation-first testing for OESIS components and integrations.
- Ensure coverage for functional, regression, API, integration, system-level, and compatibility testing.
- Analyze test results, identify defects, and work with developers to resolve issues.
- Apply AI/ML techniques to improve test coverage, defect detection, and test maintenance.
- Explore intelligent test generation, self-healing automation, smart test selection, and failure analysis.
- Integrate automated tests into CI pipelines such as Jenkins or GitHub Actions.
- Investigate customer-reported issues and continuously improve QA processes.

## Required Skills

- 2+ years as QA Automation Engineer.
- 2+ years building/maintaining automation frameworks.
- 2+ years programming in Python, Java, or Groovy.
- Functional, regression, exploratory, and API testing.
- CI pipelines, Git, Agile/Scrum, analytical thinking, and English communication.

## Preferred Skills

- AI/ML concepts in software testing.
- Experience applying AI tools to improve testing efficiency or coverage.
- SDK/library/system-level testing, cross-platform testing, JMeter, debugging tools, and logs.

## Salary / Benefits

Salary is not disclosed.

## AI / Automation Relevance

Very strong AI relevance: the posting explicitly emphasizes AI-first testing, AI/ML techniques, intelligent test generation, self-healing automation, smart test selection, and failure analysis.

## AI Impact Analysis

AI can improve test coverage and reduce maintenance effort, but self-healing or generated tests can hide real quality risks if not reviewed. QA engineers still need strong debugging, coverage analysis, and judgment.
