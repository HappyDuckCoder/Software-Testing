## Job Description

HCLTech Vietnam is hiring a Data Test Engineer for the HCLTech x ANZ banking digital transformation project. The role focuses on data testing, ETL testing, AWS data services, data warehousing, and data quality frameworks.

## Key Responsibilities

- Support data testing for a banking digital transformation project.
- Validate ETL extraction, transformation, and loading behavior.
- Work with AWS Lambda, Glue Job, Athena, S3, and Redshift.
- Test data storage formats such as Parquet, Avro, JSON, governed tables, and Iceberg.
- Use data transformation and testing frameworks such as dbt, Great Expectations, and Soda.
- Collaborate with analysts and engineers.

## Required Skills

- Python, Rust, GoLang, or Java scripting.
- Strong SQL knowledge.
- AWS Lambda, AWS Glue Job, Amazon Athena, Amazon S3.
- AWS Redshift and data warehousing.
- ETL testing.
- dbt, Great Expectations, Soda.

## Nice-to-have Skills

- Tableau, Qlik, or similar tools.
- CI/CD, GitHub, Codefresh, Terraform.
- Data modeling and collaboration with analysts/engineers.

## Salary / Benefits

Salary is not disclosed. Benefits include hybrid working, collaboration with ANZ, 18 paid leave days/year, full-salary insurance plan, 13th-month salary, medical benefits, onsite travel chances, snacks, parking, and internal training.

## AI / Automation Relevance

No explicit AI/LLM skill is listed, but the role is closely related to data quality and automated data validation.

AI can help generate SQL checks and detect data anomalies, but banking data testing requires deterministic validation, traceability, and reproducible evidence.
