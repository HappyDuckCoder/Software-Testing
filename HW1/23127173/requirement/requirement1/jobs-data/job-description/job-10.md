## Job Description

The Quality Assurance Engineer ensures the quality, stability, and performance of mobile and web applications. The role validates Flutter mobile applications, ReactJS web applications, hardware integrations, sensor responsiveness, video recording stability, and backend API integrations.

## Key Responsibilities

- Define testing strategies, acceptance criteria, and quality standards.
- Create and maintain test plans, scenarios, and test cases.
- Perform manual and automated functional, regression, integration, and UAT testing.
- Identify, document, prioritize, and track defects.
- Validate mobile and web behavior.
- Build and maintain automated test suites.
- Evaluate performance, responsiveness, scalability, load, and stress behavior.
- Validate long-session video recording, playback reliability, memory usage, and app stability.
- Test sensors, hardware workflows, pose tracking responsiveness, and calibration flows.
- Verify frontend/backend integrations through API testing.
- Communicate testing results, risks, and recommendations.

## Required Skills

- 7+ years of software QA/testing experience.
- Manual and automated testing methodologies.
- Selenium, Appium, XCUITest, or similar frameworks.
- REST API and backend testing.
- Flutter mobile app testing and ReactJS web app testing.
- Flipper, Android Studio Profiler, Xcode Instruments.
- Agile and SDLC understanding.

## Preferred Skills

- Native iOS and Android testing.
- Performance and load testing tools.
- Linear or similar bug/project tracking tools.
- Computer vision or motion-tracking technologies such as MediaPipe.
