# HW05 Agent Skills Catalog

| Skill | Dùng khi | Kết quả |
| --- | --- | --- |
| `performance-testing-and-log-analysis` | Chuẩn bị hoặc rà soát toàn bộ performance-testing workflow. | Trace từ endpoint, plan đến raw evidence và AI review. |
| `jmeter-e2e-plan-builder` | Dựng/rà soát JMeter plan cho workflow E2E. | Plan data-driven, token/ID extraction, assertions và scenario settings. |
| `transactional-test-data-manager` | Chuẩn bị dữ liệu cho request làm thay đổi trạng thái. | Tài khoản/đơn độc lập, quy trình seed/reset và kiểm tra trước chạy. |

Các skill chỉ hỗ trợ quy trình; log `.jtl`, HTML report, ảnh monitor/phần cứng và video phải do sinh viên tạo từ lần chạy thật.
